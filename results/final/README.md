# Final results: index

Everything here is generated by `python scripts/final_results.py` from the saved result files; nothing is typed by hand.

- [consistency_check.md](consistency_check.md): **32 checks**, all PASS. Each number is recomputed from the per-claim predictions and compared with the Phase 3/4/5 files and README.md.
- [manifest_sha256.txt](manifest_sha256.txt): hashes of all result files.
- `T3_unrounded.csv` (from `python scripts/unrounded_ci.py`): unrounded BAcc, differences and CIs for T3. Reported values are rounded once from these. Example: the random-deferral lower bound is −2.36497 (−2.36), although T3 stores −2.365.
- `report_figures/` (from `python scripts/report_figures.py`): print-size figures (16 cm wide), drawn from the saved result files only.

## Labels: measured vs simulated

- **Measured:** the single-model times (Phase 3, per claim on the T4) and the end-to-end cascade run (Phase 4, Kaggle version 6).
- **Simulated:** cascade, majority-vote and random-deferral times, computed by adding measured per-claim latencies.
- **Accuracy is never simulated:** the end-to-end run reproduced all 12,949 cascade predictions exactly.
